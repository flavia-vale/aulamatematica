Uma linha por rodada, uma coluna vazia esperando a próxima. É o formato inteiro
do acompanhamento — não crie outro relatório.

**Convenção de contagem, fixada e imutável:** todos os números vêm da **soma da
aba "Países"** do Search Console, período de 12 meses. O painel-resumo mostra
número diferente porque inclui linhas sem país atribuído. Misturar as duas entre
meses transforma a série em ficção.

## Como ler esta tabela

**A linha que mais importa é "consultas distintas".** É quantas buscas
diferentes trazem alguém até o site. No projeto de origem ela quadruplicou
enquanto o número de páginas quase não mudou — as mesmas páginas passaram a
responder mais perguntas.

**Taxa de clique caindo enquanto tudo mais sobe não é piora.** É o site passando
a aparecer em muito mais buscas, inclusive onde não é a melhor resposta. No
projeto de origem a CTR caiu de 3,63% para 3,07% enquanto os cliques iam de 40
para 177. Olhar a CTR isolada teria produzido a conclusão oposta e errada.
